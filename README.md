# 🏦 Banking Data Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing banking data using Microsoft Power BI. It uses a dataset of **30,000 banking records** to explore customer demographics, banking products, loan and insurance amounts, bank performance, and account status.

The dashboard helps transform raw banking data into meaningful insights through interactive data visualizations and business metrics.

## 🎯 Project Objectives
- Analyze customer demographics and employment types.
- Compare public and private sector banks.
- Understand banking product distribution.
- Analyze loan, deposit, insurance, and card records.
- Monitor customer account and product status.
- Identify patterns that support data-driven decision-making.

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **Microsoft Excel / CSV** – Data source and data handling
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs, where applicable

## 📂 Dataset Description
The dataset contains **30,000 records and 20 columns**, covering:

- Bank name and bank type
- Branch city
- Customer age, gender, and employment type
- Annual income and credit score
- Product category and product name
- Product amount, interest rate, and tenure
- Processing fees and monthly EMI or premium
- Insurance partner
- Start date and status

## 📊 Dashboard Features
- Banking performance analysis
- Public vs. private bank comparison
- Customer demographic analysis
- Product category and product-level analysis
- Loan and insurance analysis
- Account status monitoring
- Interactive charts, KPIs, and filters, where implemented

## 🔍 Key Insights from the Dataset
- **30,000** banking records are available for analysis.
- **8 banks** are represented in the dataset.
- **15 cities** are covered.
- Public-sector banks account for 15,666 records, while private-sector banks account for 14,334 records.
- Loans are the largest product category by record count, with 18,310 records.
- The dataset contains 16,638 Active records, 11,842 Closed records, 922 Pending records, and 598 Defaulted records.

## 🚀 How to Use
1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Banking.pbix`.
4. If prompted, update the dataset file path.
5. Refresh the data if necessary.
6. Explore the dashboard using the available filters and visualizations.
